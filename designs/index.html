Dashboard design directions

Five mobile-first mocks with the same dummy data. Pick a favorite (or a hybrid) and the rest get deleted.

  1. Newsprint Editorial / NYT feel. Serif headlines, cream paper, hairline rules.
  2. Reader Pocket/Readwise vibe. Quiet typography, no card chrome, system light/dark.
  3. Bento Apple/Linear bento grid. Rounded cards, per-widget accent color.
  4. Terminal Monospace, ASCII dividers, amber-on-black dark default.
  5. Brutalist All-caps, hard borders, electric accent, max density.
